🔐 Jogo do Código Secreto

Jogo de adivinhação feito com HTML, CSS e JavaScript. O computador sorteia um código secreto entre 1 e 10, e a pessoa precisa descobrir qual é, recebendo dicas de "maior" ou "menor" a cada palpite.
Projeto de estudo, com identidade visual e código próprios.

🎮 Como jogar
Digite um número entre 1 e 10 no campo de palpite.
Clique em Enviar Palpite.
O jogo dá uma dica: o código secreto é maior ou menor que o número digitado.
Continue tentando até acertar.
Ao acertar, o jogo mostra em quantas tentativas você descobriu o código, e o botão Novo Jogo é liberado para jogar de novo.

✨ Funcionalidades
Sorteio de um código secreto aleatório entre 1 e 10
Lista de números já sorteados, para que o mesmo código não se repita em jogos seguidos (a lista é reiniciada quando todos os números já saíram)
Dicas de "maior" ou "menor" a cada palpite errado
Contador de tentativas, com mensagem no singular ou no plural
Limpeza automática do campo após cada palpite errado
Botão Novo Jogo desabilitado até o jogador acertar
Layout responsivo, com ajustes para telas menores

🛠️ Tecnologias
HTML5: estrutura da página
CSS3: estilização, variáveis de cor, flexbox e media queries
JavaScript: lógica do jogo e manipulação do DOM
Google Fonts: fonte Montserrat (títulos em Times New Roman)
